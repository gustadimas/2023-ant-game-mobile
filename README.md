# Ant Game

Projeto da faculdade, de set/2023. Subi pro GitHub em novembro de 2026 só pra guardar, sem mexer no código.

Jogo mobile de tocar nas formigas. Elas saem de dois spawners e, quando você toca em cima de uma, o `Tap.cs` detecta com um raycast 2D, elimina a formiga e soma ponto. Tem menu e som.

## Como abrir

Na época só exportei a pasta Assets num `.unitypackage`, então não tem ProjectSettings. Crie um projeto 2D vazio no Unity (nessa época eu usava a 2021.3) e importe `pacote-original/AntGame.unitypackage` em Assets > Import Package > Custom Package.

## Créditos

A arte está em `Assets/_Game`. Usa TextMesh Pro.
